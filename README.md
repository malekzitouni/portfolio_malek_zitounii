# Portfolio — Malek Zitouni

Site statique (HTML / CSS / JS), sans build. Déploiement Vercel :

1. Mettre le contenu de ce dossier à la racine d'un dépôt GitHub (index.html à la racine).
2. Vercel → Add New → Project → importer le dépôt.
3. Framework Preset : Other. Laisser Build Command et Output Directory vides. Deploy.

Fichiers à personnaliser : index.html (textes, liens), assets/Malek_Zitouni_CV.pdf (CV),
assets/malek.webp (photo), assets/og-image.png (aperçu LinkedIn / réseaux sociaux).
